# 隧道收敛测缝台

测量员登记测缝计号（铭牌）、里程桩号与收敛毫米值。接口进程内后台线程认领待判行（不另起 worker 容器），按绝对值是否不超过 3.0 mm 给出合格或超限。页面是 Svelte。

## 校准到期拦截

- 每个测缝计号登记一个"校准有效期至"，存 `joint_meters` 一张表：报送拦截口与"校准到期专页"读的是同一行，改一处两边同时生效。
- 校准过期的铭牌不许再报送：`POST /api/logs` 返回 403，提示"请先办理续期后再开报"，并在 `meter_blocks` 留下拦截原因，专页表格显示该号最近一次拦住原因。
- 测量员可在专页修改到期日（含续期），每次改动在 `meter_renewals` 留痕（旧日期 → 新日期、操作人、时间）。
- 续期与报送在同一瞬间对撞时，数据库用同一把事务级咨询锁串行化，只有一种结局：不会既收下报送又显示过期。
- 巡检员账号只读：可看报送台与到期专页，不能报送、不能改期。

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16
